## 1. 概述

### 1.1 背景与目标

平台当前对空调用电的呈现分散在两处：

- **综合监控大屏**：今日/本月累计能耗、空调实时负荷三张卡片，能耗趋势（按天/按月）、能耗排行（房间/租户）、日使用详情曲线。定位是"看板式实时展示"，不支持深入的历史回溯与多维分析。
- **电费相关模块**：当量记录、抄表记录、运行时间记录、日使用情况、用电量统计等。定位是"计费与记录查询"，以表格明细为主，不提供分析视角。

本模块新增 **"能耗分析"一级菜单**，面向项目管理者与节能运营人员，围绕空调用电提供系统化的历史能耗分析能力，目标：

1. **收拢**综合监控大屏中已有的能耗展示内容，并在此基础上扩展分析深度；
2. **支持按不同时间粒度**（按小时/按日/按月/按年）查看与钻取历史能耗数据，本期聚焦按天、按小时的用电统计分析；
3. **覆盖空调用电的主要分析场景**：总量与趋势、同比环比对比、对象对比、自定义区域汇总（群组/电表）、排行与结构占比、负荷分析、能效关联、报表导出；
4. 为节能策略（环境感知联动、极致节能、负荷调控）的效果评估提供数据视角。

### 1.2 功能定位与模块边界

| 相关模块   | 关系与边界                                                                                       |
| ------ | ------------------------------------------------------------------------------------------- |
| 综合监控大屏 | 大屏是驻留展示（无交互深度）；能耗分析是操作型分析页面。大屏三卡片、能耗趋势、能耗排行、日使用详情的内容全部被本模块覆盖并增强。大屏本身不做改动。                   |
| 电费相关   | 电费模块回答"电费是多少、如何分摊"（账务口径）；能耗分析回答"电用在哪、怎么变化、是否合理"（分析口径）。本模块不读取电价配置，不计算或展示任何费用/成本指标，与电费模块完全解耦。 |
| 节能策略   | 本模块不做策略配置，仅提供用能数据视角；对比分析可用于策略启用前后的效果对照。                                                     |
| 故障预警   | 能耗类异常事件（电表通讯中断、读数回退等）的处理流程在故障预警/电费相关模块完成，本模块不设异常提示入口。                                             |
| 集中控制   | 集中控制的"群组控制"是控制指令分组；本模块"群组管理"是分析视角的房间组合，两者相互独立、互不影响。                                         |

### 1.3 设计原则与方案取舍

**采用方案**：一级菜单"能耗分析"下设 7 个二级功能页面，每页聚焦一个分析场景（详见第 2 章）。

**曾考虑的备选方案**：

- 方案 A：单页 + 页内 Tab 切换全部场景。放弃原因：单页过重，与现有菜单模式（一级组 + 二级页）不一致，后续按页迭代困难。
- 方案 C：做成第三块"能耗分析大屏"（与总览大屏、监控大屏并列的直达页）。放弃原因：大屏形态不支持复杂筛选与钻取，无法满足"按不同时间维度查看历史数据"的核心诉求。

**设计原则**：

1. 只基于平台已有数据链路（电表抄表、内机当量、负荷/温度采样、楼栋-楼层-房间结构、租户关系）定义指标，不引入无数据支撑的指标（单位面积能耗、碳排放折算本期均不做）；
2. 页面遵循平台内页规范（暗色主题、`_base.css` 筛选栏/表格/分页组件），不是大屏视觉；
3. 各页之间可通过参数联动下钻（总览 → 趋势/排行/负荷）；
4. 原型阶段全部使用确定性模拟数据，保证页内、页间数值自洽。

### 1.4 术语约定

| 术语    | 定义                                      |
| ----- | --------------------------------------- |
| 能耗    | 空调用电量，单位 kWh（度）                         |
| 当量    | 室内机按小时采集的用电折算量，是房间/租户级能耗的数据来源           |
| 负荷    | 空调用电功率，单位 kW，按 15 分钟粒度采样                |
| 同比    | 与上一年同期比较（日→去年同日，月→去年同月，年→上年）            |
| 环比    | 与相邻上一周期比较（日→前一日，月→上月；自定义区间→前一等长紧邻区间）    |
| 公区    | 公共区域空调（走廊、大堂等），对应电费模块"公区空调分摊"概念         |
| 群组    | 用户在群组管理中自定义的房间组合或电表组合（群组类型二选一），仅用于能耗分析，与集中控制的控制群组相互独立 |
| 统计对象  | 分析的实体维度：项目整体 / 楼栋 / 楼层 / 房间 / 租户 / 群组 / 电表（不提供空调系统维度） |

├── 对比分析

### 2.3 可见性与权限

- 本模块按项目特性显隐：**无电表的项目隐藏"能耗分析"一级菜单**（无电表即无能耗数据可分析）；原型阶段以"模拟项目电表数为 0"演示显隐效果；用户停留在能耗分析任一页面时若切换至无电表项目，主壳自动导航回"项目总览大屏"，避免停留在菜单已隐藏的无数据页面；
- 外部入口一致性：其他模块（如综合监控大屏卡片）若配置跳转能耗分析的入口，无电表项目下应一并隐藏或禁用；当前原型大屏未配置此类跳转，无需演示；
- 正式开发时按平台"菜单按钮"权限体系控制到二级菜单粒度，导出操作单独设按钮权限；原型阶段不体现权限差异。

## 3. 数据基础

### 3.1 数据来源与链路

| 数据 | 采集粒度 | 支撑的分析层级 | 现有出处 |
|---|---|---|---|
| 电表抄表读数 | 小时 | 项目 / 楼栋 / 电表级能耗（读数差值） | 电费相关-抄表记录、用电量统计 |
| 室内机当量 | 小时 | 房间 / 租户 / 群组 / 内机级能耗（分摊） | 电费相关-当量记录、日使用情况 |
| 负荷（功率） | 15 分钟 | 负荷曲线、最大负荷、平均负荷 | 综合监控大屏-实时负荷、日使用详情 |
| 温度（设定/室内） | 15 分钟 | 负荷-温度关联曲线 | 综合监控大屏-日使用详情 |
| 楼栋-楼层-房间树、租户、群组 | 配置数据 | 统计对象维度 | 项目及设备管理、租户管理、群组管理（唯一权威源：共享文件 `pages/_fleet.js`） |

### 3.2 分析维度与层级

- 空间层级：**项目 → 楼栋 → 楼层 → 房间（→ 内机）**，逐级向上汇总，各级之和等于上一级；
- 平行维度：**租户**（跨房间归组）、**电表**（单选查看，多台合计需在群组管理建电表群组）、**群组**（自定义房间组合或电表组合）、**公区/租户区**；
- 统计对象统一使用"类型 + 具体对象"两级选择组件（`$eobj`）：楼栋/楼层/房间三级级联下拉（楼栋→楼层→房间），租户/群组/电表扁平单选，不提供空调系统维度。

### 3.3 时间粒度与范围约束

| 粒度 | X 轴点位 | 可选范围约束 | 默认值 |
|---|---|---|---|
| 按小时 | 小时（24 点/日） | 单日（选定某一天） | 今日 |
| 按日 | 自然日 | ≤ 92 天 | 本月 |
| 按月 | 自然月 | ≤ 36 个月 | 近 12 个月 |
| 按年 | 自然年 | 近 3 年（受数据保留期限制） | 近 3 年 |

- 时间快捷项融入范围选择控件（按日：今日/昨日/本周/本月/上月/本年；按月：本月/上月/本年；按年：本年/去年/近三年；按小时：今日/昨日）；
- 时间范围统一使用起止一体范围控件（`$erange`）：面板内左侧快捷项、右侧日历点选——第一次点击选起始、第二次点击选截止；按小时退化为单日选择，按月/按年切换为月份/年度面板；
- 切换粒度时控件形态联动（单日 ↔ 日期范围 ↔ 月份范围 ↔ 年度范围），超出范围约束时提示并截断。

### 3.4 指标定义

| 指标 | 单位 | 计算口径 | 说明 |
|---|---|---|---|
| 累计能耗 | kWh | Σ 对象在统计期内的小时能耗 | 项目级取电表差值，房间/租户/群组级取当量分摊 |
| 实时负荷 | kW | 最近一次 15 分钟采样功率 | 仅总览展示 |
| 最大负荷 | kW | 统计期内 15 分钟负荷最大值，记录发生时间 | |
| 平均负荷 | kW | 统计期能耗 ÷ 统计期小时数 | |
| 同比增长率 | % | （本期 − 去年同期）÷ 去年同期 × 100% | 对比期无数据或基数绝对值 < 1 个单位时显示 `--`（小基数下变化率无意义） |
| 环比增长率 | % | （本期 − 上一周期）÷ 上一周期 × 100% | 同上 |
| 公区能耗占比 | % | 公区能耗 ÷ 项目总能耗 × 100% | |

### 3.5 数据时效与缺数处理

- 能耗数据按小时汇集，页面数据时效 **T+1 小时**；"今日/本期（进行中）"的数值为动态值；负荷与温度曲线为 15 分钟采样链路，时效约 15 分钟，实时负荷 KPI 取最近一次采样；
- 电表通讯中断、读数回退等异常时段的数据：趋势图中该点位以灰色空心样式标识"数据缺失/待补"，汇总值旁以 ⓘ 角标提示"含异常时段，已按补数规则估算"；明细行尾 ⓘ 支持点击查看异常原因与补数说明（如"电表通讯中断，已按补数规则估算"），并指引前往 电费相关-用电量统计-异常处理 完成处理；补数与异常处理流程沿用电费模块既有机制，本模块只读展示；原型模拟数据无真实缺数场景，趋势/负荷明细的 ⓘ 标识属正式开发需求，原型阶段不演示；
- 历史数据保留期按 **3 年**设计。同比所需的"去年同期"数据在保留期内，同比分析正常出数；超出保留期的更早数据按缺数规则处理。

## 4. 功能详细定义

> 通用约定：各页顶部为筛选栏（`_base.css` 的 `fb/fi/fl` 结构），下方为图表卡片与明细表格；所有图表随窗口缩放自适应；所有明细表支持导出（原型阶段导出按钮触发轻提示"导出任务已生成"；正式开发导出为异步任务，接入统一任务/下载中心查询进度与下载）；查询无结果时显示平台统一空态（📄 暂无数据）。时间范围统一使用起止一体范围控件（`$erange`），统计对象统一使用"类型+具体对象"两级选择组件（`$eobj`），两者为共享组件（`pages/_energy-filter.js`）。

### 4.1 能耗总览（energy-overview）P0

**功能定位**：进入能耗分析的默认首页。回答"这个项目的空调电用得怎么样"，承接综合监控大屏三张能耗卡片的内容并扩展同环比视角；卡片本身不可点击，仅通过各卡片右上"更多 ›"入口跳转对应分析页。

**页面布局**：

本页为固定周期的汇总首页，**不设筛选栏**：各模块统计周期固定并在模块标题中注明（今日/本月/本年/近 30 天/近 7 天），页面右上角显示数据更新时间。需要自定义时间范围时通过"更多 ›"进入对应分析页。KPI 卡仅作数据呈现，无点击跳转。

```
┌─ KPI 卡片行（6 张，仅展示不可点击） ────────────────────────────┐
│ 今日能耗    本月能耗    本年能耗   本月日均能耗   实时负荷    今日最大负荷 │
│ +迷你趋势   +环比上月   +同比上年   (按天均)     (kW)       +发生时间   │
├─ 图表行 1 ──────────────────────────────────────────────────┤
│ 能耗趋势(柱状,占 1/2,近7天/近30天/本月/本年切换,图例在标题行) │ 能耗结构(环形,占 1/2,公区/楼栋/租户切换) │
├─ 图表行 2 ──────────────────────────────────────────────────┤
│ 能耗排行 TOP10(条形,房间/租户切换)      │ 今日负荷曲线(15 分钟采样,标注峰值)  │
└──────────────────────────────────────────────────────────────┘
```

**模块定义**：

| 模块 | 内容与口径 | 交互 |
|---|---|---|
| KPI-今日能耗 | 今日 0 点至当前累计 kWh + 与昨日同时段对比箭头 + 24h 迷你趋势线；取数与综合监控大屏"今日累计能耗"卡片一致 | 仅数据呈现，无点击跳转 |
| KPI-本月能耗 | 本月累计 kWh + 环比上月全月% | 同上 |
| KPI-本年能耗 | 本年累计 kWh + 同比上年同期% | 同上 |
| KPI-本月日均能耗 | 本月累计能耗 ÷ 本月已统计天数 | 同上 |
| KPI-实时负荷 | 最近采样功率 kW；取数与大屏"空调实时负荷"一致 | 同上 |
| KPI-今日最大负荷 | 今日最大负荷 kW + 发生时刻 | 同上 |
| 能耗趋势 | 能耗柱状图（日粒度叠加 7 日移动平均线；本年切换为按月柱状、无移动平均线）；标题行含 近 7 天/近 30 天/本月/本年 快捷切换，图例（日能耗/7 日移动平均）显示在切换按钮右侧、"更多"左侧 | 卡片不可点击；"更多 ›"→ 趋势分析（默认本月，不带卡片当前所选时段） |
| 能耗结构 | 本月能耗结构环形图（含电量与占比），支持 公区/租户区、楼栋、租户 维度切换 | 卡片不可点击；"更多 ›"→ 排行与结构-能耗结构 Tab（对应当前维度） |
| 能耗排行 TOP10 | 本月能耗 TOP10 条形，房间/租户切换 | 卡片与条目不可点击；"更多 ›"→ 排行与结构-能耗排行 Tab（对应当前维度） |
| 今日负荷曲线 | 今日 15 分钟负荷曲线，标注峰值与发生时刻 | 卡片不可点击；"更多 ›"→ 负荷分析（今日） |

**边界与空态**：新项目无历史数据时 KPI 显示 `--`；同环比对比期无数据显示 `--`。

### 4.2 趋势分析（energy-trend）P0

**功能定位**：核心分析页。任意统计对象在任意时间粒度下的历史能耗趋势、汇总指标与明细数据。综合监控大屏"能耗趋势"（按天/按月）是本页的子集。

**页面布局**：

```
┌─ 筛选栏：统计对象(类型+具体对象两级) | 时间粒度(按小时|按日|按月|按年) | 时间范围(范围控件) ─┐
│            查询 / 重置 / 导出 ────────────────────────────────────────┤
├─ 汇总条：总能耗 | 周期均值 | 最大值 | 最小值 ─────────────────────────────┤
├─ 主图表：柱状(本期) + 折线(叠加项)；未勾选叠加项时不显示图例 ──────────────────┤
├─ 明细表：时间 | 能耗(kWh) | 环比期能耗(kWh) | 环比% | 同比期能耗(kWh) | 同比% ────┤
└─ 分页 + 导出 ───────────────────────────────────────────────────┘
```

**筛选定义**：

| 控件 | 规则 | 默认值 |
|---|---|---|
| 统计对象 | 类型+具体对象两级选择（`$eobj`）：类型含项目整体/楼栋/楼层/房间/租户/群组/电表（无空调系统）；楼栋/楼层/房间为三级级联下拉（楼栋→楼层→房间），租户/群组/电表为扁平单选；群组下拉标注群组类型（房间群组/电表群组）；电表单选，多电表合计需先在群组管理建电表群组 | 项目整体 |
| 时间粒度 | 按小时/按日/按月/按年四档（按小时仅小时计量周期项目可选），粒度切换联动范围控件形态（见 3.3） | 按日 |
| 时间范围 | 起止一体范围控件（`$erange`）：按小时=单日选择；按日=日期范围；按月=月份范围；按年=年度范围；快捷项融入面板左侧 | 本月 |

**汇总条**：4 项——总能耗、周期均值（当前粒度各点位值的算术平均：按小时即小时均值、按日即日均、按月即月均）、最大值、最小值；同比/环比不在汇总条展示，在明细表逐行展示。

**主图表**：本期能耗为柱状（蓝色渐变，沿用大屏柱状风格）；环比期、同比期曲线**默认叠加**（折线，无需勾选），对比期无数据的序列自动省略。悬浮 tooltip 显示该点位本期/叠加期数值与差值%。叠加曲线为**对比期原始值**按点位对齐展示，明细表中的环比%/同比%为**变化率**，两者口径不同、互不矛盾。

**明细表**：按粒度逐行（按小时=所选日 24 行、按日=逐日、按月=逐月、按年=逐年），列：时间、能耗(kWh)、环比期能耗(kWh)、环比%、同比期能耗(kWh)、同比%；对比期无数据时对应列显示 `--`。各粒度对比口径：按小时=昨日/去年同期**同时段**（今日 08:00 ↔ 昨日 08:00 ↔ 去年同期 08:00），按日/按月/按年=上一周期/上年同期。异常时段行尾 ⓘ 标识规则见 3.5（原型不演示）。

**入口参数**（供其他页下钻）：`?gran=&from=&to=&obj=`，进入时按参数回填筛选并自动查询；`obj` 支持群组/电表传参（`obj=group:群组ID`，可为房间群组或电表群组；`obj=meter:电表ID`，仅支持单台）。

**边界**：本页单次仅支持 1 个统计对象（多对象横向对比请使用对比分析页）；群组视为 1 个统计对象；电表统计对象为单选，多电表合计分析需先在群组管理创建电表群组后按群组查询；范围超约束时提示"最长可查询 N，已自动截断"。

### 4.3 对比分析（energy-compare）P1

**功能定位**：回答"和过去比怎么样"与"对象之间差多少"。支撑节能改造/策略启用前后的效果对照、楼栋租户间横向对标。

**页面布局**：页首"时间对比 | 对象对比"两个页签；两种模式均支持导出（原型为轻提示）。

**模式一：时间对比** — 同一对象、两个时段

| 项 | 定义 |
|---|---|
| 筛选 | 统计对象（类型+具体对象两级，同趋势分析）；时间粒度（四档）；本期范围（范围控件，随粒度切换形态）；对比方式：环比期(自动) / 同比期(自动) / 自定义（仅选对比起始，结束按本期跨度自动等长推算并跟随显示） |
| 图表 | "时间用能对比"：双序列分组柱状图（本期 vs 对比期，X 轴按粒度对齐点位），无副标题注解 |
| 汇总卡 | 本期总量、对比期总量、差值、差值率、期均差值（随粒度：小时均/日均/月均/年均） |
| 明细表 | 本期时间 | 本期能耗(kWh) | 对比时间 | 对比期能耗(kWh) | 差值 | 差值率% |
| 边界 | 两期跨度强制等长（自定义对比期=起始+本期跨度自动推算）；推算结果超出数据窗口时截断至窗口边界 |

**模式二：对象对比** — 同一时段、多个对象

| 项 | 定义 |
|---|---|
| 筛选 | 对象层级（楼栋/楼层/房间/租户/群组/电表，无空调系统，单层级内多选 2~10 个）；时间粒度（四档）与范围（范围控件，随粒度切换形态） |
| 图表 | 多序列折线图（每对象一色，最多 10 色） |
| 对比表 | 转置布局：列为各对比对象，行为统计项——期间总能耗(kWh)、期间平均(kWh/时·日·月·年，随粒度)，其后按粒度逐行一个时间点位的能耗 |
| 边界 | 跨层级混选不允许；超过 10 个对象提示"最多对比 10 个" |

### 4.4 排行与结构（energy-rank）P0

**功能定位**：回答"谁用得多、结构是否合理"。综合监控大屏"能耗排行"是本页排行模块的子集。

**页面布局**：页首"能耗排行 | 能耗结构"两个页签。

**能耗排行 Tab**：

| 项 | 定义 |
|---|---|
| 筛选 | 维度：房间/租户/楼层/楼栋/群组/电表（无空调系统）；指标固定为能耗；日期范围（范围控件，默认本月）；范围：TOP10/20/50/全部；排序：倒序(默认)/正序 |
| 图表 | 横向条形图（数值 + 占所选合计%标签） |
| 表格 | 排名 | 对象 | 能耗(kWh) | 占所选合计% | 同比% (↑↓箭头着色：升红降绿) | 操作 |
| 交互 | 操作列"查看趋势"→ 趋势分析（带对象与时段参数）；支持导出 |

> 注：排行表"占所选合计"的分母为当前 TOP N 范围内对象的合计；能耗结构"占比"的分母为项目全量。两者口径不同，不可直接对照。

**能耗结构 Tab**：

| 项 | 定义 |
|---|---|
| 分组维度 | 租户（默认）/ 楼栋 / 楼层 / 公区 vs 租户区，以切换按钮形式置于结构图表标题行（不占筛选栏） |
| 筛选 | 日期范围（范围控件，默认本月）；不提供导出 |
| 图表 | 环形图，图例含各分组电量与占比 |
| 明细 | 分组 | 能耗(kWh) | 占比% | 较上期变化(百分点，上期=当前统计时段的上一等长周期：今日→昨日 / 本周→上周 / 本月→上月 / 自定义→前一等长紧邻区间) |

### 4.5 负荷分析（energy-load）P0

> 优先级说明：本页承载综合监控大屏"日使用详情"与"实时负荷"的既有内容，属于"覆盖大屏已有内容"的必要范围，故定为 P0。

**功能定位**：从功率视角分析用电合理性与平稳度。承接综合监控大屏"日使用详情"（温度/负荷曲线）与"空调实时负荷"。本期不展示峰谷时段相关内容。

**页面布局**：

```
┌─ 指标卡行：最大负荷+发生时间 | 平均负荷 | 日平均设定温度 | 日平均室内温度 ──┐
├─ 日负荷曲线(统计对象：项目整体/电表/电表群组；单日选择，15 分钟粒度)          │
│   负荷 kW 主轴 + 平均设定温度/平均室内温度(右轴℃，默认全部显示，无需勾选)     │
│   最大负荷点自动标注                                                    │
├─ 明细表(当日 96 点)：时刻 | 负荷(kW) | 平均设定温度(℃) | 平均室内温度(℃) ────┤
└─ 分页 + 导出 ───────────────────────────────────────────────────────┘
```

**关键口径**：负荷数据来源于电表，统计对象仅支持项目整体（全部电表合计）/ 单台电表 / 电表群组（两级选择）；负荷曲线为 15 分钟采样（单日 96 点）；最大负荷记录发生时刻；平均负荷为当日负荷点均值；日平均设定温度、日平均室内温度为当日对应温度点均值；负荷曲线按所选对象当日能耗等比缩放。温度-负荷相关性以 Pearson 相关系数口径评估（r = 负荷序列与温度序列的皮尔逊相关，页面不展示，供正式开发参考）。

**空态**：无负荷采样数据时图表区显示平台统一空态；明细表异常时段行尾加 ⓘ 标识（原型不演示，见 3.5）。

### 4.6 能耗报表（energy-report）P1

**功能定位**：面向留档与汇报的结构化报表输出，减少人工整理。本期仅支持手动查询与导出，不做定时生成与邮件/站内推送。报表为"单对象 × 时间行"形态：选定一个统计对象，按粒度逐点位列出能耗。

| 项 | 定义 |
|---|---|
| 统计对象 | 类型+具体对象两级选择（同趋势分析）：项目整体/楼栋/楼层/房间/租户/群组/电表 |
| 时间粒度 | 按小时 / 按日 / 按月 / 按年；按小时即为日报：选定某一天，数据按 24 小时逐小时列出 |
| 时间范围 | 范围控件（`$erange`）：按小时=单日选择；按日=日期范围（逐日列出）；按月=月份范围（逐月列出）；按年=年度范围（逐年列出） |
| 表格字段 | 时间 \| 能耗(kWh) \| 环比% \| 同比% |
| 汇总行 | 表尾合计行（期间能耗合计 = 各时间点位能耗之和） |
| 操作 | 手动查询、导出 Excel（原型阶段导出触发轻提示） |

环比/同比口径：同比为本期与上年同期比较，环比为本期与上一等长周期比较，对比期无数据显示 `--`；页面不设页头注解与表格标题注解。

### 4.7 群组管理（energy-group）P1

**功能定位**：维护"自定义区域汇总"所需的群组，支持两种类型：**房间群组**（任意房间组合，如"三层整层""VIP 客房区"）与**电表群组**（任意电表组合，替代趋势分析中电表的多选合计需求）。两类型互斥，新增/编辑时二选一。群组在趋势分析、对比分析、能耗报表中作为独立统计对象使用。

**列表页**：页面注解合并为一处"说明："样式注释（群组仅用于能耗统计；房间群组与电表群组不可混合；同一房间或电表可加入多个群组；群组仅定义统计口径，不影响设备控制和历史能耗数据）。列表上方设筛选栏（群组名称关键字 + 群组类型：全部/房间群组/电表群组 + 查询/重置，查询对当前数据实际过滤、重置恢复全量）。

| 列 | 说明 |
|---|---|
| 群组名称 | 项目内唯一；成员含失效项时名称旁追加"N 个成员失效"提示 |
| 群组类型 | 房间群组 / 电表群组 |
| 成员数量 | 群组内有效成员数量（房间数或电表数，随类型而定） |
| 成员名称 | 成员摘要，最多展示 3 个，超出显示"等 N 个"，完整名单悬浮提示 |
| 备注 | 选填说明 |
| 创建时间 | |
| 操作 | 编辑 / 删除（删除弹二次确认对话框） |

**新增/编辑（弹窗表单）**：

| 字段 | 规则 |
|---|---|
| 群组名称 | 必填，≤ 20 字，项目内唯一，重名提示 |
| 群组类型 | 必填，单选：房间群组 / 电表群组；已选成员时切换类型需二次确认"切换群组类型将清空已选择的成员，是否继续？" |
| 成员（房间/电表） | 必填，≥ 1 个；房间群组用建筑物勾选树（支持搜索、仅房间层级可勾选、父子节点勾选联动）；电表群组用电表列表多选，支持按名称/标识搜索 |
| 备注 | 选填，≤ 50 字 |

**边界与规则**：

- 同一房间/电表可属于多个同类型群组；房间群组与电表群组的成员池互不相通；群组成员可跨楼栋/楼层任意组合；
- 群组成员对应的房间或电表被删除后，群组列表与选择器中标注"N 个成员失效"，查询时自动忽略失效成员，不报错；点击失效徽标可**一键清理失效成员**（二次确认后按当前有效成员保存群组）；
- 能耗口径：房间群组 = 成员房间当量分摊合计；电表群组 = 成员电表读数差值合计（与单台电表统计口径一致）；
- 群组不存储独立能耗数据，查询时按成员实时汇总，因此编辑群组成员后历史趋势按最新成员口径重现；
- 本群组仅用于能耗分析，与集中控制-群组控制的"控制群组"相互独立、互不影响；
- 群组按项目隔离，项目切换后仅显示当前项目群组；
- 删除群组不影响任何已存储的能耗数据，仅移除该分析视角。

- 采用工程既有**确定性伪随机**模式（`seedRand`，以"项目名 + 日期"为种子），同一项目同一日期任意页面取数一致，刷新不变；
- 量级基准与现有原型对齐：项目日能耗 400~1000 kWh（对齐大屏趋势 556~988 与今日 392.1 的量级）、负荷 0~80 kW、设备规模 92 电表 / 620 空调（618 台已绑定，对应 `_fleet.js` 中 140 个唯一房间）/ 20 租户样本；群组样本 3~5 个（房间群组成员 3~10 个房间，跨楼层组合；电表群组成员 2~6 台电表）；
- 层级自洽：内机 → 房间 → 楼层 → 楼栋 → 项目逐级求和一致；小时求和 = 日，日求和 = 月，月求和 = 年；群组能耗 = 成员房间之和；
- 总览 KPI 取数须与综合监控大屏卡片同量级同逻辑（本期**不改动大屏取数**；大屏后续切换到 `_energy-data.js` 列为可选优化项）；
- 项目切换：读取 `localStorage.fyProj`，不同项目产出不同数据（种子含项目名）；主壳切换项目时已有 iframe 刷新机制，无需额外处理；模拟项目中应包含 1 个电表数为 0 的项目，用于演示菜单显隐。

## 7. 实施规划与验收

### 7.1 迭代划分（原型制作顺序）

| 迭代 | 范围 | 里程碑 |
|---|---|---|
| 迭代 1（P0 核心） | `_energy-data.js` 数据层 + 菜单接入 + 能耗总览 + 趋势分析 | 一级菜单可用，核心分析闭环跑通 |
| 迭代 2（P0 补齐） | 排行与结构 + 负荷分析 | 大屏已有内容全部被覆盖并增强 |
| 迭代 3（P1） | 对比分析 + 能耗报表 + 群组管理 | 七页全量，模块完整交付 |

### 7.2 验收要点（每页通用）

1. 切换项目后数据刷新，且不同项目数值不同、同项目刷新后数值不变（确定性种子生效）；
2. 时间粒度与范围控件联动生效（按小时=单日、按日/月/年=对应范围面板、范围截断提示）；
3. 页间跳转参数正确回填（总览各卡"更多 ›"→ 对应分析页；排行"查看趋势"→ 趋势分析带对象与时段）；
4. 数值自洽：明细求和 = 汇总条 = 总览 KPI 同口径值；报表合计 = 各时间点位能耗之和；群组能耗 = 成员之和；
5. 空态覆盖：无数据时段、无电表项目（"能耗分析"菜单整体隐藏）、对比期无数据（`--`）；
6. 窗口缩放与侧栏折叠后图表自适应无变形；
7. 综合监控大屏原有功能不受影响（本期零改动）；
8. 群组管理 CRUD 生效（新增/编辑/删除二次确认、重名校验、房间树勾选联动），趋势分析中群组/电表对象正常出数。
