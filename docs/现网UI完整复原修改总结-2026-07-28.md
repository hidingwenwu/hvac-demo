# 现网平台 UI 完整复原 · 修改总结（2026-07-28）

## 一、任务范围

以测试环境 `http://test-m.achelp.cn` 为基准，使用两个账号（`chanpintest1`：单项目物业管理员；`dingwenwu`：经销商/技术支持，全项目全页面）逐项核对现网界面，将 hvac-demo 原型工程与现网平台 UI 做到完整复原，并保证原型内部关联配置逻辑自洽。

本轮共修改 **15 个文件**、新增 **2 个文件**，59 个原型页面加载全部无 JS 报错。

## 二、核对方法

- 通过浏览器自动化登录现网，分别采集两个账号的菜单树、36+ 个页面截图与页面 DOM；
- 对关键计费项目（`平台测试_新计费`、`二次分摊-H`、`分摊计费-ly`、`平台测试_后付费`、`产品部测试-按小时预付费`）逐一切换项目，确认菜单与页面形态随项目类型的变化规则；
- 结构比对（筛选项/表头/按钮逐项 diff）+ 截图人工复核双重确认；
- 修复后在浏览器中逐页回归验证。

### 2. 共享机队数据源（新增 pages/_fleet.js）—— 关联配置逻辑自洽

新增唯一权威数据源，解决"空调与房间关系"与"空调控制"两页数据脱节问题：

- 620 台内机（1号楼，3/7/9/14/23 层 × 124 台），字段含楼栋/楼层/房间/内机地址/内机标识名称/容量/租户/绑定态；
- localStorage（`hvacFleetV2`）持久化：绑定、解绑、内机标识名称、容量、租户、新建建筑即时写入；
- 两页加载同一份数据，天然同步。

**联动效果（已端到端验证）**：
- 在"空调与房间关系"的关系列表中填写内机标识名称（如"东2"）→ "空调控制"卡片标题即时变为 `302-东2`，详情面板"空调名称"同步显示；
- 绑定/解绑内机 → 两页的已绑定/未绑定数量与建筑树同步变化；
- 新建建筑 → 出现在两页建筑树中（绑定内机后在空调控制页可见）。
