# 控制器管理：下发分体控制器配置（含 FD01G 支持）

> 2026-08-03 · 页面：`pages/device-controller.html` · 验证：`testcase/verify-controller-dispatch.cjs`（42 断言）

## 一、背景与现网调研结论

现网（test-m.achelp.cn，项目「平台测试_分体机」，2026-08-03 实测）控制器管理-主机管理页支持对第三方分体机控制器按型号多选后「下发配置」；飞奕自研 FD01G 尚未支持（勾选后提示「请选择分体空调主机」）。本次在原型中：① 复刻现网第三方交互；② 按同一页面逻辑新增 FD01G 下发配置。

现网实测行为（原型均已复刻）：

| 操作 | 现网提示/行为 |
| --- | --- |
| 未勾选主机点「下发配置」 | 请先勾选主机 |
| 勾选含非分体机型号（E74G/A02FG/A02EG 等） | 请选择分体空调主机 |
| 跨型号多选（如 oc+dbx） | 请选择同一型号的主机 |
| 同型号勾选 | 打开「下发分体控制器配置」弹窗 |

弹窗形态：标题「下发分体控制器配置」，首行「当前控制器型号：X」，每个配置项独立「下发」按钮，底部「取消」。

## 二、各型号配置项

| 型号 | 配置项 | 来源 |
| --- | --- | --- |
| oc / dbx | 空调品牌代码（十进制，确认文案含十六进制换算） | 现网实测；20260116 批量下发品牌代码原型 |
| hrjn | 空调类型（壁挂机/单相柜机/三相柜机）+ 空调品牌代码 + 待机功耗（W） | 现网实测（下拉选项实测采集） |
| **FD01G（本次新增）** | 见下 | 需求 + FD01G 蓝牙小程序原型 0509 |

FD01G 配置项与校验规则：

1. **空调品牌代码**：十进制非负整数，确认文案含十六进制换算；
2. **电流互感器辅助判断开关机状态**：开关控件；开启时显示「电流阈值」（整数 ≥50，默认 100，单位 mA），下发时连同开关状态一并确认；关闭状态下发即确认关闭；
3. **电量采集配置**（分组）：
   - 供电模式：单相模式/三相模式；三相时显示提示「本设备仅采集一相电流，请根据所采相位合理设定电压有效值和功率因数…」；
   - 电压有效值 (U)：非负数，默认 220V；
   - 功率因数 (cosΦ)：0–1，默认 1，带红字警示「设置不当可能导致用电量计算误差较大」；
   - 底部公式提示：单相 P = U × I × cosΦ；三相 P = √3 × U × I × cosΦ。

与现网差异（有意为之）：① FD01G 视为已支持（本次需求目标）；② 型号行追加「（已选 N 台）」便于演示说明，现网无此后缀。

## 三、模拟数据

在原有 E74G×5 / A02FG×2 基础上，参照测试环境补入分体机控制器 7 台：FD01G×2（FD01G分体控制器 / 1235）、hrjn×2、dbx×2、oc×1（命名与编号沿用现网风格），共 14 台。
