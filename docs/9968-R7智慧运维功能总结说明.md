## 2. 建设目标

在“智慧运维”菜单下增加 R7 产品专属的监控和查询能力，使运维人员能够：

1. 从仪表盘快速掌握全部在网 R7 设备的在线、运行、故障、流量、版本和品牌构成。
2. 在设备列表中按多种条件查询 R7 设备，并查看设备主要状态。
3. 为未绑定项目的 R7 设备补充所属项目。
4. 从设备列表直接进入指定设备详情，或在详情页按项目选择设备后读取数据。
5. 在详情页原有功能区上方展示 R7 网关基本信息，并支持刷新当前设备基本信息。

本轮不提供“添加设备”功能。

拉取设定、历史参数、参数曲线、参数筛选等均为平台已有功能，不属于禅道 9968 的需求开发范围。本次原型中对这些区域的补齐仅用于与已有功能页面保持一致，本文不再说明其业务逻辑和交互。

## 3. 页面与菜单

“智慧运维”下新增三个菜单页面：

| 菜单 | 页面文件 | 页面职责 |
| --- | --- | --- |
| R7 仪表盘 | `pages/ops-r7-dashboard.html` | 展示 R7 设备总体运行和构成统计 |
| R7 设备列表 | `pages/ops-r7-list.html` | 查询、筛选、绑定项目并进入设备详情 |
| R7 设备详情 | `pages/ops-r7.html` | 选择或接收指定设备，并在原有功能区上方展示网关基本信息 |

菜单注册和 iframe 页面跳转位于 `hvac-demo.html`。

## 4. 公共数据和状态约定

当前原型数据统一由 `pages/_r7-data.js` 提供。正式开发时应以服务端接口替换模拟数据，但字段语义和页面行为应保持一致。

### 4.1 设备主要字段

| 字段 | 说明 |
| --- | --- |
| `sn` | R7 产品 SN，唯一标识设备 |
| `project` | 所属项目，空值表示未绑定项目 |
| `trafficPlan` | 月流量套餐，单位 M |
| `trafficRemain` | 剩余流量，单位 M |
| `version` | 当前软件版本 |
| `latestVersion` | 最新可用软件版本 |
| `productVersion` | 产品版本，当前为“标准版”或“MAX版” |
| `outdoorBrand` | 外机品牌 |
| `indoorBrand` | 内机品牌 |
| `online` | 在线状态 |
| `address` | 项目地址 |
| `systemStatus` | 系统状态，当前为“开机”或“关机” |
| `systemModes` | 当前系统模式列表 |
| `outdoorErrors` | 外机故障码列表 |
| `indoorErrors` | 内机故障码列表 |
| `lastCommunicationAt` | 最近通信时间 |

### 4.2 业务判断口径

| 指标 | 判断规则 |
| --- | --- |
| 流量预警 | `trafficRemain < 50M` |
| 可升级 | `version !== latestVersion` |
| 有故障 | 外机故障码或内机故障码任一列表非空 |
| 运行系统 | `systemStatus === '开机'` |
| 在线率 | 在线设备数 / 设备总数，按整数百分比展示 |
| 内外机组合 | `外机品牌 + 内机品牌`，例如“美的 + 大金” |

### 4.3 前端状态存储

| 存储项 | 存储位置 | 用途 |
| --- | --- | --- |
| `hvac:r7:selectedSn` | `sessionStorage` | 列表进入详情时记录当前设备 SN |
| `hvac:r7:projectBindings` | `localStorage` | 原型中持久化设备项目绑定结果 |

正式接入后，项目绑定必须改为服务端持久化；页面刷新后应重新读取服务端最新状态。

## 5. R7 仪表盘

### 5.1 统计内容

仪表盘展示以下内容：

1. 设备总数。
2. 在线设备、运行系统、故障系统、流量预警四项核心指标。
3. 设备在线率：饼图，附在线和离线数量。
4. 产品版本：仅使用饼图展示标准版和 MAX 版构成，不展示柱图，也不展示“可升级设备”。
5. 软件版本分布：同时展示饼图比例和横向柱图数量。
6. 外机品牌分布：按设备数量降序展示。
7. 内机品牌分布：按设备数量降序展示。
8. 内外机组合分布：展示饼图比例和横向柱图数量，默认取数量前 20 名。

### 5.2 页面布局

第一行布局顺序为：

1. 设备总数单卡。
2. 在线设备、运行系统、故障系统、流量预警组成的田字格。
3. 设备在线率。
4. 产品版本。
5. 软件版本分布。

其中设备在线率和产品版本采用紧凑卡片宽度，卡片下方的分类统计使用上下排列，避免横向内容拥挤。

第二行为外机品牌分布和内机品牌分布。

第三行为内外机组合分布，卡片内部采用三段式布局：

1. 左侧为组合占比饼图。
2. 中间为组合图例。
3. 右侧为组合数量横向柱图。

窄屏下按照“饼图、图例、柱图”顺序自动转为上下排列。

### 5.3 图表交互

所有饼图均支持鼠标悬浮提示。光标落在某个扇区时，显示：

- 分类名称。
- 设备数量。
- 占比。

光标离开饼图后提示隐藏。卡片标题右上角不再展示“实时”“饼图 / 柱图”“设备数 / 占比”“默认前 20 名”等辅助小字。

## 6. R7 设备列表

### 6.1 快捷统计筛选

页面顶部提供五个快捷筛选入口：

| 快捷筛选 | 行为 |
| --- | --- |
| 设备总数 | 清空全部筛选并展示所有设备 |
| 在线 | 设置在线状态为“在线” |
| 运行系统 | 设置系统状态为“开机” |
| 故障系统 | 设置故障状态为“有故障” |
| 流量预警 | 设置流量状态为“预警” |

快捷筛选为单选状态，当前项通过高亮和 `aria-pressed` 标识。点击快捷筛选时会清空其他普通筛选条件。

### 6.2 普通筛选

| 筛选项 | 控件 | 规则 |
| --- | --- | --- |
| 设备 SN | 手动输入 | 支持模糊匹配，不区分大小写，按 Enter 可查询 |
| 所属项目 | 下拉 | 支持具体项目和“未绑定” |
| 流量状态 | 下拉 | 正常、预警 |
| 软件版本 | 下拉 | 从当前设备数据动态生成 |
| 产品版本 | 下拉 | 标准版、MAX版 |
| 外机品牌 | 下拉 | 从当前设备数据动态生成 |
| 内机品牌 | 下拉 | 从当前设备数据动态生成 |
| 在线状态 | 下拉 | 在线、离线 |
| 系统状态 | 下拉 | 开机、关机 |
| 升级状态 | 下拉 | 可升级、最新 |
| 故障状态 | 下拉 | 有故障、无故障 |

筛选默认项使用字段名称，不带“全部”前缀；选项使用精简文案，例如“正常”“预警”“未绑定”“最新”。

筛选框和“查询/重置”按钮位于同一个自适应布局中：

- 控件根据页面可用宽度自动伸缩和换行。
- SN 和项目保留较大的基础宽度，短选项下拉使用较小基础宽度。
- 查询、重置按钮紧跟最后一个筛选项，不固定另起一行。
- 页面宽度不足时，筛选项和按钮自然换行，不产生页面级横向滚动。

### 6.3 列表字段

列表展示：

1. 产品 SN，同时展示产品版本。
2. 所属项目。
3. 流量套餐和剩余流量。
4. 软件版本和升级状态。
5. 外机品牌。
6. 内机品牌。
7. 在线状态。
8. 项目地址。
9. 系统状态。
10. 外机故障状态。
11. 内机故障状态。
12. 操作。

列表支持每页 10、20、50 条数据。

### 6.4 绑定项目

当设备未绑定项目时，所属项目列显示“绑定项目”按钮。点击后：

1. 弹出绑定项目窗口。
2. 显示当前设备 SN。
3. 选择所属项目并确认。
4. 列表立即更新项目名称。
5. 刷新页面后绑定结果仍保留。

已绑定项目的设备直接展示项目名称，不显示绑定按钮。

### 6.5 进入详情

点击列表“详情”时：

1. 记录当前设备 SN。
2. 通知主框架切换到 R7 设备详情。
3. iframe 地址携带 `?sn={设备SN}`。
4. 详情页直接展示指定设备，无需再次筛选和读取。

## 7. R7 设备详情

### 7.1 两种进入方式

#### 菜单直接进入

页面初始不展示设备相关内容，只展示空状态。用户必须：

1. 点击“筛选”。
2. 选择项目并查询该项目内的 R7 设备。
3. 单选设备并确认。
4. 点击“读取”。
5. 读取成功后展示网关基本信息及页面原有功能区。

如果当前账号仅能查看一个项目，可自动选中该项目并查询设备。

#### 设备列表进入

页面通过 URL 参数接收设备 SN。SN 有效时直接读取并展示设备详情；SN 无效时保持空状态并提示未找到设备。

### 7.2 设备筛选弹窗

筛选弹窗包含：

- 项目下拉框。
- 查询按钮。
- 当前项目 R7 设备表格。
- 设备单选框。
- 分页控件，支持每页 10、20、50 条。
- 取消和确定按钮。

未选择项目直接查询时提示“请选择项目”；未选择设备直接确认时提示“请选择R7设备”。确认设备后只回填 SN，不立即展示下方详情，仍需点击“读取”。

### 7.3 网关基本信息

读取设备后，在页面原有功能区上方展示：

- 产品 SN、所属项目、流量情况。
- 软件版本、升级状态、产品版本。
- 外机品牌、内机品牌、在线状态。
- 项目地址、系统状态。
- 外机故障、内机故障。
- 系统模式。
- 最近通信时间、最近刷新时间。

“刷新”按钮重新读取当前设备基本信息，更新最近刷新时间，并提示“设备信息刷新成功”。

## 8. 响应式和视觉要求

1. 新增页面沿用 HVAC Demo 现有深色运维平台风格。
2. 卡片、表格、按钮、弹窗和状态颜色保持现有组件习惯。
3. 仪表盘在 1920、1366 和 480 宽度下不得出现页面级横向滚动。
4. 设备列表筛选区自动伸缩和换行；列表表格允许在自身容器内横向滚动。
5. 设备详情筛选弹窗在移动端宽度不超过视口，底部操作按钮可见；设备表格允许在弹窗内部横向滚动。
6. 所有动态文字必须在容器内正常截断或换行，不遮挡相邻内容。

## 9. 开发接入注意事项

1. 当前页面为原型实现，本文涉及的 R7 设备和统计数据均为本地模拟数据。
2. 正式接口应保留本说明中的字段含义、筛选语义和统计口径。
3. 项目权限应由后端返回当前账号可见项目，详情页不得查询无权限项目的设备。
4. 列表和详情中的项目绑定结果、设备状态和基本信息必须使用同一数据源，避免页面间不一致。
5. 统计接口应明确数据更新时间；仪表盘数据刷新后需要重新计算全部卡片。
6. 内外机组合统计只在展示层简化为“外机品牌 + 内机品牌”，接口无需拼接展示名称。
7. 设备详情通过列表跳转时应校验 URL 中的 SN 是否仍在当前账号权限范围内。
8. 所有接口失败场景需补充统一错误提示、重试入口和加载状态；当前原型只覆盖前端交互。

## 10. 验收摘要

满足以下条件可判定本轮功能达到原型验收要求：

1. 智慧运维菜单下三个 R7 页面可正常打开。
2. 仪表盘所有统计卡片、图表和悬浮提示正常，统计口径一致。
3. 设备列表所有筛选、快捷筛选、重置、分页、项目绑定和详情跳转正常。
4. 详情页两种进入方式行为符合要求，未读取设备时不展示设备相关内容。
5. 网关基本信息展示完整，列表与详情数据一致，刷新功能正常。
6. 桌面、平板和移动端页面无异常遮挡或页面级横向溢出。
7. 自动化静态测试和浏览器交互测试通过。
