## 2. 测试说明

### 2.1 优先级定义

| 优先级 | 说明 |
| --- | --- |
| P0 | 核心主流程，失败将导致页面或主要业务不可用 |
| P1 | 重要功能、校验和跨页交互，失败会明显影响使用 |
| P2 | 边界、视觉、兼容性和辅助交互 |

### 2.2 原型测试基准

当前原型使用 `pages/_r7-data.js` 中的模拟数据。执行测试前清理与 R7 相关的浏览器本地存储，首次加载时统计基准如下：

| 指标 | 预期值 |
| --- | --- |
| 设备总数 | 12 |
| 在线设备 | 9 |
| 离线设备 | 3 |
| 设备在线率 | 75% |
| 运行系统 | 8 |
| 故障系统 | 5 |
| 流量预警 | 4 |
| 标准版 | 6 |
| MAX版 | 6 |

建议重点使用以下设备：

| SN | 用途 |
| --- | --- |
| `R7-110108-240612-0007` | 已绑定“中关村软件园”，用于列表查询、详情读取和参数功能 |
| `R7-510107-240318-0036` | 初始未绑定项目，用于绑定项目及持久化测试 |

原型中的项目绑定与拉取设定保存在浏览器 `localStorage`。重复执行相关用例时，应先删除 `hvac:r7:projectBindings` 和 `hvac:r7:pullSettings:{SN}`，避免上一次测试结果影响本次预期。

## 12. 自动化回归建议

现有自动化脚本：

- `testcase/verify-r7-operations-ui.cjs`：静态检查页面结构、关键文案、存储键及功能入口。
